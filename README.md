# CVRP repository 
Репозиторий создан для демонстрации домашних работ и семинаров в рамках курса "Семинар наставника" по задаче маршрутизации транспорта с ограничениями грузоподъемности(CVRP).\
Данные можно получить с [сайта](http://vrp.atd-lab.inf.puc-rio.br/index.php/en/)

## Структура репозитория

- **[main.py](https://github.com/DanLip02/CVRP/blob/v1/main.py)**: Изначальный скрипт (возможноо будет финальным решением)
- **[main_2.py](https://github.com/DanLip02/CVRP/blob/v1/main_2.py)**: Попытка улучшить решение засчет учета нулевой точки.
- **[best_try.py](https://github.com/DanLip02/CVRP/blob/v1/best_try.py)**: Скрипт с финальным решением + прогонкой по всем дата-сетам. 
- **[dataset_B.py](https://github.com/DanLip02/CVRP/blob/v1/dataset_B.py)**: Скрипт содержит в себе все тесты, которые находятся на сайте (блок B). 
- **[dataset_P.py](https://github.com/DanLip02/CVRP/blob/v1/dataset_P.py)**: Скрипт содержит в себе все тесты, которые находятся на сайте (блок P). 
- **[dataset_E.py](https://github.com/DanLip02/CVRP/blob/v1/dataset_E.py)**: Скрипт содержит в себе все тесты, которые находятся на сайте (блок E).  
- **[GA_HSE_results](https://github.com/DanLip02/CVRP/blob/v1/GA_HSE_results)**: Презентация результатов.
